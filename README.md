# beautiful-lyrics-plus
Changes Spotify's default lyrics on mobile to something much more beautiful

The lyrics background uses two drifting layers of blurred album artwork with smooth cover fades, artwork-aware shading, and sparse color recovery for mostly dark covers. Image preparation runs once per cover off the UI thread; animation pauses while hidden and respects the background quality setting.

Synced lyrics use individually positioned rows with staggered eased motion. The wave starts at the top visible row and continues through completed, active, and upcoming lines, with a 36 ms step that tapers and caps at 140 ms. Normal transitions finish in roughly half a second. Songs start with a small 24 dp top margin; later active rows align at 25% of the viewport height. Drag anywhere in the viewport, including directly on a lyric or interlude: movement tracks the finger, and momentum slows to a stop with scroll bounds. Playback following pauses while browsing and resumes on a line change only when the active lyrics are visible and scrolling has been idle for 500 ms. Tapping a lyric seeks and returns to following it.

TypeScript controls following, gestures, inertia, virtualization, and measurements through SpotifyPlus's UI worklets, and prepares lyric effect curves once. One Android frame callback animates visible rows and glyphs directly, avoiding per-glyph JavaScript work and property transfers during playback. Row animations share an absolute frame clock, so skipped frames preserve their stagger rather than restarting the delays together. A single parent view moves the list during manual scrolling; delayed rows receive individual corrections during automatic following. A bounded render window preloads upcoming rows, and cached measurements avoid repeated layout work. Lyric glow and syllable effects pause during manual motion to keep dragging smooth. The native gradient renderer caches text widths, reuses shaders, and changes their matrix instead of allocating a new gradient per frame. The motion is inspired by [applemusic-like-lyrics](https://github.com/amll-dev/applemusic-like-lyrics).

Run `npm test` for scrolling geometry, overlapping lyric timing, follow suspension, stagger phases across missed frames, inactive effects clocks, frame-independent momentum decay, and render-window checks.

Interludes reserve space only while playing and during their short exit animation. Finished and upcoming interludes collapse completely, including their extra row gap. The layout retains their measured heights for seeking back and preserves the visible lyric's position when a completed interlude collapses.

Build with `npm run build` using JDK 21 and Android SDK Platform 35. Configure your SDK path in `src/native/local.properties` first. The build compiles the native Android extension in release mode and packages the APK beside `dist/index.js`. Commit the generated `dist/lyrics.apk` along with the JavaScript bundle when updating the marketplace repository; an empty placeholder APK cannot load on Android.
